# OSINT Competitive Research & Telegram AI — v1.0.0

Создано 2026-10-29 для рабочей папки **Web Design Studio | OpenDesign**.

## Содержимое
- `SKILL.md` — главный агентный навык в формате Agent Skills.
- `references/` — сценарии маркетплейсов, сайтов/SEO/контента, Telegram, архитектура n8n и правила доступа.
- `assets/` — отчёт, пример конфигурации Telegram-бота, промпт будущего ассистента и критерии проверки MVP.
- `PROJECT-INSTRUCTIONS.md` — короткая инструкция для проекта ChatGPT.

## Как применять
1. В проекте ChatGPT читать и применять `SKILL.md` при анализе конкурентов, SEO, сайтов или проработке Telegram-бота. Наличие файла в библиотеке не обязательно означает автоматическую регистрацию навыка во всех чатах.
2. Для локального Codex/совместимого агента скопировать **всю** папку `osint-competitive-research` в поддерживаемую директорию Skills (точный путь сверить с настройками клиента).
3. Для Telegram начать с `references/telegram-policy.md`, затем `references/telegram-bot.md`, `references/telegram-implementation.md` и checklist. Не использовать образец конфигурации в продакшне без секретов, проверок и согласований.

## Примеры запросов
- «Применяй osint-competitive-research: сравни публичные карточки наших городских рюкзаков с 5 конкурентами, раздели факты и гипотезы».
- «Исследуй 3 сайта-конкурента KOMPREL Digital и предложи изменения первого экрана; не выдумывай конверсии».
- «Подготовь 10 тем Reels на основе подтверждённых веб-источников и интересов пользователей; укажи ссылки».
- «Спроектируй Telegram AI-помощника SYMMETLINE для ответов по упоминанию в разрешённой группе; укажи права, opt-in, n8n-узлы и тесты».

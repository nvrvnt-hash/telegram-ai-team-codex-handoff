# Реестр инструментов и проверок

Дата проверки: 2026-10-29. Не утверждать сохранность тарифов, доступности и возможностей без новой проверки.

| Источник | Для чего | Оговорка |
|---|---|---|
| https://tools.osintnewsletter.com/ | Каталог OSINT-инструментов | Каталог, не пакет устанавливаемых AI-скиллов |
| https://thunderbit.com/ | Парсинг разрешённых веб-страниц | Ограничения сайтов, тарифы и выгрузки проверять |
| https://web.archive.org/ | История сайтов | Покрытие архива неполное |
| https://urlscan.io/ | Техническое изучение публичного URL | Не отправлять секретные URL |
| https://host.io/ | Доменные связи | Общий IP не значит общий владелец |
| https://lens.google/ | Визуальный поиск | Совпадение не доказывает права |
| https://tineye.com/ | Обратный поиск изображений | Нет результата ≠ изображение уникально |
| https://filmot.com/ | Поиск в YouTube-субтитрах | Покрытие ограничено индексом |
| https://channeltimeline.cc/ | История публикаций каналов | Только доступные публикации |
| https://29a.ch/photo-forensics/ | Визуальные признаки редактирования | Не заключение о достоверности |
| https://c2palab.com/ | C2PA-происхождение | Манифест может отсутствовать |
| https://core.telegram.org/bots/api | Telegram Bot API | Интеграция требует токен и backend |
| https://core.telegram.org/bots/features | Guest Mode, группы, privacy, AI | Проверять обновления Bot API |
| https://telegram.org/tos/bot-developers | Ограничения ботов | Запрещены спам и лишний сбор данных |
| https://telegram.org/tos/content-licensing | Ограничения Telegram scraping/AI | Публичный контент не означает свободу сбора |

Telegram-поисковики из стороннего OSINT-каталога (например Lyzem/Telegago) **не включаются** в автоматизированный пайплайн данных для LLM или хранилище переписок из-за правил Telegram о scraping и AI. Не обещать их легальный режим использования без дополнительной проверки конкретного сценария.

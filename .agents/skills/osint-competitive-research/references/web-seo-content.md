# Сайты, SEO, реклама, контент и видео

## Сайты и разработка
- Wayback Machine (https://web.archive.org/) — история версий (доступна не для всех URL, не является полным архивом).
- urlscan.io (https://urlscan.io/) — скриншот/сетевые запросы/технические связи; проверять публичность и видимость отправляемых URLs; не отправлять закрытые страницы и токены.
- Host.io (https://host.io/) — домены, DNS, инфраструктурные связи, без автоматического вывода об общем владельце.
- Firecrawl — при подключении извлекать страницы, ссылки, тексты, структуру для сравнения.

## SEO
1. Исследовать структуру ТОП-страниц и типы интента; поиск по региону и периодам.
2. Разделить подтверждённые факты, рекламные заявления и предложения по улучшению.
3. Проверить каннибализацию/повторы на собственном сайте, затем формировать уникальный план без копирования чужих статей.
4. Метрики органики оценивать на собственной Search Console/Яндекс Вебмастере при доступе; не приписывать конкурентам недоступные данные.

## Контент и ролики
- Filmot (https://filmot.com/) — поиск слов в доступных субтитрах YouTube; использовать для поиска темы/вопроса, а не присваивания чужих сценариев.
- Channel Timeline (https://channeltimeline.cc/) — хронология публичных YouTube-публикаций; без вывода о доходности или продажах.
- Проверка визуалов: TinEye, Google Lens, Forensically (https://29a.ch/photo-forensics/), C2PA Lab (https://c2palab.com/). Отсутствие метаданных/следов не доказывает оригинальность.

## Рекламная разведка
Сравнивать только публичные рекламные креативы, офферы, CTA и посадочные страницы; отдельно перепроверять доступные официальные библиотеки рекламы. Не выводить из креатива рекламный бюджет, таргетинг, конверсии или CPA.

## Формат результата
Три уровня: «наблюдение с URL», «интерпретация», «гипотеза для A/B-теста»; далее текстовое ТЗ для дизайна/SEO/креатива. Использовать Hallmark/OpenDesign для дизайна и Human Writer RU для редакторских материалов (когда доступны).

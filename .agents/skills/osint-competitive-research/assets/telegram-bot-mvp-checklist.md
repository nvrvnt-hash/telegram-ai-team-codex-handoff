# Telegram AI-бот: критерии MVP и тестирования

## Перед разработкой
- [ ] Утверждена роль (SYMMETLINE или KOMPREL Digital), запрещена подмена роли.
- [ ] Есть бот из @BotFather, токен находится в секретном хранилище.
- [ ] Подтверждена база знаний, нет выдуманных цен/характеристик.
- [ ] Есть тексты /privacy, /delete, /stop, сценарий согласия.
- [ ] Согласован 1 тестовый групповой чат с администратором.

## Функциональные проверки
- [ ] /start работает, раскрывает идентичность AI и коммерческую связь.
- [ ] Личный входящий вопрос обрабатывается после необходимого согласия.
- [ ] При отсутствии данных бот задаёт вопрос или предлагает менеджера.
- [ ] В чужой/неразрешённой группе бот молчит.
- [ ] В разрешённой группе без @mention/reply/команды бот молчит.
- [ ] Ответы не спамят ссылками и не продолжаются после /stop.
- [ ] /delete выполняет предусмотренное удаление.
- [ ] /human передаёт обращение только с нужным согласием.
- [ ] Нет записи полного потока групповых сообщений.
- [ ] Нет зацикливания при ответах других ботов.
- [ ] Дубликаты Telegram updates не вызывают повторной отправки.
- [ ] Ошибка 429 приводит к корректному повтору по retry_after.
- [ ] Глобальное отключение работает.

## После MVP (НЕ входит в текущую версию)
- [ ] Guest Mode проверен на поддерживаемых чатах.
- [ ] CRM включена с надлежащим информированием.
- [ ] Аналитика обращений обезличена/агрегирована.
- [ ] Отдельная оценка рисков новых каналов общения.

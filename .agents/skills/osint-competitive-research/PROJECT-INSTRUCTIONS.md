# Короткая инструкция для проекта Web Design Studio | OpenDesign

При задачах конкурентного анализа, публичных исследований сайтов, SEO, маркетплейсов, рекламы, контента и разработки Telegram AI-ассистента используй методологию `osint-competitive-research/SKILL.md` и тематические материалы папок `references/` и `assets/`. Отделяй подтверждённые факты от гипотез, приводи исходные ссылки и дату наблюдения, не выдумывай метрики. Для Telegram придерживайся `references/telegram-policy.md`: только разрешённые чаты и обращения, прозрачная идентичность бота, минимум данных, согласие и без спама/скрейпинга. Для визуала и копирайтинга сохраняй согласованность с Hallmark и OpenDesign. Не изменяй существующие проектные файлы без явного поручения.

Добавить этот текст в инструкции ChatGPT Project можно вручную. Размещение SKILL.md среди файлов само по себе **не гарантирует автоматическое обнаружение и активацию** как зарегистрированного навыка.

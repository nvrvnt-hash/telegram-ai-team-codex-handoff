# Цели продукта и критерии успеха

## Зачем
Одна Telegram AI Team для владельца проектов SYMMETLINE/магазин рюкзаков и KOMPREL Digital: решать рабочие задачи через управляющего, который выбирает 1–3 специалистов, и консультировать пользователей в Telegram.

## Два режима — обязательны
1. **Приватный управленческий:** разрешённые ID владельца/администраторов, менеджер и роли marketing, design, analytics, seo, content, support, research. Отдельная история, конфигурация и доступ к будущим внутренним данным.
2. **Публичный:** клиентские личные сообщения и согласованные группы. Только ответы по подтверждённым публичным сведениям, прозрачное позиционирование AI-помощника, возможность обратиться к человеку; без доступа к приватному контуру.

## Основные роли
- Manager: классификация, маршрутизация и сведение результатов, остановка на конфликте данных;
- marketing: УТП, рекламная стратегия и сегменты;
- design: UI/UX, брифы и концепции, не утверждает создание графики без инструмента;
- analytics: KPI и расчёты строго из предоставленных чисел;
- seo: структура, семантика, SEO-рекомендации без вымышленных частот;
- content: посты и сценарии роликов;
- support: ответы по базе знаний и эскалация;
- research: законное исследование открытых веб-источников, без скрейпинга Telegram для AI-датасетов.

## Готовность MVP
- Администратор пишет задачу в личку -> видит выбранные роли и проверяемый результат;
- Обычный посетитель пишет в личку -> не может вызвать внутренние роли и получить секретные данные;
- Неавторизованная группа игнорируется, разрешённая — отвечает по явному обращению;
- Контакт с AI и обработка данных понятны участникам; доступны /privacy, /stop, /delete, /human согласно разработанной политике;
- Тесты имитируют эти сценарии без Telegram и OpenAI API, ручная проверка выполняется отдельно;
- Результаты без источников не выдают за верифицированные; цена, наличие и сроки не придумываются;
- Есть квоты и контролируемая стоимость, логирование без исходного текста запросов по умолчанию, кнопка аварийной остановки;
- Возможен запуск локально на Windows 11, описана остановка и резервное копирование служебной БД.

## Не делаем в первой версии
- Не создаём множество Telegram-аккаунтов для ролей.
- Не собираем участников групп и не начинаем с ними диалог без обращения.
- Не создаём массовые рекламные рассылки.
- Не подключаем автоматически CRM/n8n, публикации, изменение рекламных кампаний и платёжные операции.
- Не обещаем видеогенерацию/изображения, пока не подключены соответствующие инструменты.

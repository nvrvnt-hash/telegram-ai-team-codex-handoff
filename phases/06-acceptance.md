# Этап 06 — приёмка и локальная эксплуатация

**Цель:** подтверждение готовности к ограниченному запуску, а не создание новых функций.

Проверить:
- офлайн тесты / узкие интеграционные тесты / ручной smoke в тестовых чатах;
- секреты и `.gitignore`, `git diff`, отсутствующие креденшиалы в логах;
- отключение/перезапуск, Ctrl+C, временная потеря связи, Telegram 429;
- стоимость/лимиты и безопасный режим при исчерпании бюджета;
- журнал задач, privacy consent, /stop /delete /human, список разрешённых групп;
- достаточность описания Windows-установки, резервного копирования и восстановления SQLite;
- актуальные ограничения Telegram Bot API, запреты на unsolicited outreach;
- отдельный список фич для следующей версии: RAG/товарная база, n8n/CRM, генерация изображений, веб-поиск.

**Приёмка:** запись наблюдаемых результатов и ограничений; минимальная инструкция для владельца «запуск/пауза/выключение/обновление». Не запускать продакшн или рассылки автоматически. **Остановиться.**

## Приёмка стоимости
На одинаковых тестовых задачах сравнить число вызовов, input/output tokens, ошибки и правильность ответов. Данные измерить из API usage, если подключен. Если API недоступен, пометить метрики как непроверенные; не утверждать конкретную экономию. Проверить, что рабочие логи не содержат raw prompts/PII.

# Этап 04 — личные сообщения Telegram

**Цель:** проверить end-to-end DM без риска для посторонних.

Работы:
- отработать /start /help /team /ask /tasks /delete /privacy /stop /human;
- чистые ответы, удобная разбивка длинных сообщений по Telegram ограничениям, статус обработки и таймаут;
- приватный менеджер: роли, планирование и ответ; публичный посетитель: безопасная поддержка по известным данным, иначе эскалация;
- короткая приватная память только для разрешённого пользователя и в границах согласия;
- тесты aiogram handlers с mock Bot API; корректная обработка Telegram 429/потери связи;
- отдельный чек-лист **ручной** проверки в контролируемых личных чатах (тестовый admin + тестовый обычный пользователь).

**Проверка реального Telegram:** только после того, как владелец сам добавит токены в локальный `.env` и даст команду на тест. Не требовать их отправлять Codex.

**Приёмка:** оба типа DM проверены и задокументированы (или чётко отмечено «не проверено без ключей»). **Остановиться.**

# Этап 00 — инвентаризация и аудит (read-only)

**Цель:** установить фактическое состояние MVP и подготовить безопасный порядок доработок.

**Разрешено:** читать файлы, проверять версии Python, зависимости, запускать существующие offline-тесты (если доступны). Можно создать/обновить только отчёт `reports/phase-00-audit.md`, если среда разрешает запись.

**Запрещено:** изменять `app/`, `tests/`, зависимости, `.env.example`, запускать Telegram/LLM API, добавлять новые сервисы и менять Git remote.

Проверь:
1. Текущую структуру и зависимости. Совместимость с Windows 11/PowerShell.
2. Роли менеджера, возможные маршруты через aiogram.
3. Разграничение admin/public (особенно любой пользователь в private).
4. Наличие consent/stop/delete/human и точность документации.
5. Поведение при непустых/пустых планах, параллельности, API-ошибках, лимитах.
6. Безопасность групп: allowlist, команды, @mention, reply, идентичность пользователя.
7. Тесты и пробелы. Риски по цене и утечкам.

**Приёмка:** есть перечень найденных дефектов P0/P1/P2 с путями к файлам, реальные результаты тестов, план этапа 01; исполняемые файлы не изменены. **Остановиться.**

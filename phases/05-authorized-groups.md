# Этап 05 — Telegram группы по разрешению

**Цель:** бот помогает там, где его сознательно пригласили и к нему обратились.

Работы:
- группы включаются только через ALLOWED_GROUP_IDS и согласованный администратором процесс;
- при Privacy Mode (если включён) обрабатываются @mention / reply / команды; нет автоматических ответов на все сообщения группы;
- group always public: ни одна группа не получает доступ к приватному Manager, маркетинговым данным, аналитике или памяти admin;
- дедупликация повторной доставки Telegram update и защита от bot-to-bot loops;
- удаление/отключение группы или общий kill switch без утечки данных;
- rate limits per group/user, ограничения длины, 429 backoff;
- групповым участникам ясно, что отвечает AI-бот; при отсутствии фактов — эскалация, без агрессивной рекламы;
- тесты: разрешённая/неразрешённая группа, обращение/необращение, reply, команды, неизвестные роли, повтор update, уход бота из группы.

**Приёмка:** самопроизвольных сообщений нет, конфиденциальная информация не пересекает границу. **Остановиться.**

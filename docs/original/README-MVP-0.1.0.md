# Telegram AI Team — MVP v0.1.0

**Статус:** исходный код для локального запуска, **не развернутый** бот. Один Telegram Bot API аккаунт + менеджер + 7 виртуальных специалистов. Функции: приватные диалоги, ответы на упоминания/Reply в явно разрешённых группах; автоматическая маршрутизация запроса на 1–3 роли; параллельная подготовка частей; сведение менеджером; журнал задач (без хранения исходного текста).

## Запуск на Windows 11 (PowerShell)

1. Создайте собственного бота в [@BotFather](https://t.me/BotFather). Не публикуйте токен. Укажите в описании, что это AI-команда.
2. Получите API key OpenAI. Нужен отдельный API-биллинг; подписка ChatGPT Plus сама по себе не оплачивает API.
3. Разархивируйте, откройте терминал в папке проекта, выполните:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
python -m app.main
```

Заполните `TELEGRAM_BOT_TOKEN`, `OPENAI_API_KEY`, а также доступную в API модель `OPENAI_MODEL`. **Никогда не делитесь .env.**

4. Откройте личный диалог с ботом, нажмите Start. Попробуйте `/team`, `Сделайте УТП для магазина рюкзаков`, `/ask seo: Предложи структуру страницы категории`.
5. Для групп: добавьте бота **только** в свою/согласованную группу, напишите `/chatid` от имени администратора этой группы, получите `chat_id`, внесите его в `ALLOWED_GROUP_IDS`; перезапустите. Общается по упоминанию, reply, команде. Privacy Mode оставьте включённым.

### Запуск Docker

```bash
cp .env.example .env  # заполнить секреты
mkdir -p data
docker compose up -d --build
docker compose logs -f
```

## Что сделано / что НЕ сделано

- ✅ Специалисты — самостоятельные role-prompts, менеджер маршрутизирует и соединяет результаты.
- ✅ Личка и контролируемые группы; групповой allowlist, ответы только по явному обращению.
- ✅ Короткая память последних 3 диалоговых обменов в личных чатах (до 30 мин, только RAM), без группового контекста.
- ✅ Простой лимит частоты 10 секунд на пользователя и ограничение одновременной обработки.
- ✅ Журнал задач в SQLite: ID, чат, пользователь, роли, время. Команда `/delete` удаляет журнал пользователя.
- ✅ Нет массовых рассылок, самовольных рекламных ответов или доступа к чужим группам.
- ❌ Нет подключения реальной базы товаров, файла проектов, CRM, n8n, аналитики маркетплейсов и генератора изображений. Агент-дизайнер сейчас формирует ТЗ, а не графический файл.
- ❌ Нет долговременной памяти, интеллектуального ограничения расходов и полноценной защиты от DDoS. Для публичного продакшена нужны глобальные квоты API и мониторинг бюджета.
- ❌ Нет автоматических публикаций, независимых фоновых заданий, сложных цепочек согласований или долговременной памяти диалогов.
- ❌ Не интегрирован штатный сбор метрик/трассировка в PostHog и не настроен доступ по ролям для корпоративных задач. Перед выдачей задач с конфиденциальной информацией требуется RBAC.
- ❌ Не является независимыми Telegram бот-аккаунтами: специалисты — внутренние AI-роли.

## Безопасность и ограничения

- В отличие от обычного чата, каждое входящее сообщение отправляется в OpenAI API; обеспечьте информирование пользователей и законное основание обработки данных.
- Не передавайте пароли, персональные данные и коммерческие секреты в тестовый бот. API calls используют `store=False` для снижения хранения ответа сервисом, это **не** заменяет анализ политики обработки данных и требований к конфиденциальности.
- Тексты запросов не сохраняются в SQLite, но Telegram хранит отправленные сообщения по своим правилам. `/delete` удаляет только локальный журнал.
- Не вводите token в файлы, которые попадают в Git; `.env` игнорируется Git.
- В MVP нельзя подключать инструменты, изменяющие рекламные кампании или публикующие сообщения, без отдельного механизма подтверждения администратором.
- Поскольку текущая реализация направлена на исследование и консультации, она НЕ подходит без доработок для коммерческого массового продвижения в чужих группах.

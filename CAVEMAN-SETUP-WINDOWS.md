# Caveman для Codex / VS Code на Windows 11

Проверенные официальные источники (проверено 30.10.2026):

- https://github.com/JuliusBrussee/caveman/blob/main/INSTALL.md
- https://github.com/JuliusBrussee/caveman/blob/main/SECURITY.md

## Рекомендуемый путь: skill-only, без прокси, Cloud Auto и CLI
1. Проверь, установлен ли Caveman у Codex. Если уже есть — **не устанавливай второй экземпляр**. Попроси Codex перечислить обнаруженные локальные навыки без раскрытия конфигурации/секретов.
2. Для установки навыка требуется Node.js (Skills CLI работает с Node 18+). В терминале PowerShell:
   ```powershell
   node --version
   npx --version
   ```
3. Если навыка нет и хотите добавить его **только в этот проект**, из корневой папки проекта:
   ```powershell
   npx skills add JuliusBrussee/caveman -a codex
   ```
   Перед установкой просмотрите вывод, список изменяемых файлов и разрешения. Если Skills CLI спросит о подтверждении — подтвердите только после проверки. Если уже установлен глобально, повторная установка не нужна.
4. В Codex наберите `$caveman` при необходимости явного вызова. По официальной инструкции именно `$`, не `/` — это skill в Codex. Если автоматически не действует, базовые проектные правила из `AGENTS.md` и `TOKEN-ECONOMY.md` продолжат работать.
5. Проверьте, что короткий ответ не меняет точные имена файлов, код, тесты или объяснения рисков.

## Не запускать автоматически
- `npx @caveman-ai/cli@latest` и Windows installer: расширенные возможности, но и больше интеграций/изменений. Это отдельное решение после аудита безопасности; CLI требует Node.js 22.13+.
- Caveman Proxy/Auto/managed cloud, любые hooks и маршрутизацию модели: пока не нужны для handoff. Согласно SECURITY.md, облачная Auto-маршрутизация может передавать части пользовательских запросов и контекста в Caveman Cloud.
- Не выполнять `irm ... | iex` без проверки скачанного PowerShell-скрипта.

## Об ограничениях
Нельзя обещать конкретные проценты экономии. `skill-only` прежде всего сокращает ответы и задаёт дисциплину; уменьшение входного контекста достигается правилами проекта и точечным чтением. Сокращение расходов Telegram-бота будет реализовано **в коде** по `docs/runtime-cost-design.md`.
